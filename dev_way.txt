/proc — список PID
/proc/[pid]/comm — имя процесса
/proc/[pid]/status — память

Язык разработки: Си
Поатформа: ОС Kali Linux

	Предворительный алгоритм программы: 
1. Сбор общих данных из /proc/stat и /proc/meminfo
2. Сканирование процессов (индивидуально) 
3. Сбор данных о процессах (индивидуально из каждой директории процесса)
4. Сортировка по PID (+ по потреблению CPU + по памяти)
5. Вывод на экран и обновление (top обновляет список процессов)
