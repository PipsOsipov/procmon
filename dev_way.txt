/proc — список PID
/proc/[pid]/comm — имя процесса
/proc/[pid]/status — память

Язык разработки: Си
Поатформа: ОС Kali Linux

	Предворительный алгоритм программы: 
1. Сбор общих данных из /proc/stat и /proc/meminfo
2. Сканирование процессов (индивидуально) 
3. Сбор данных о процессах (индивидуально из каждой директории процесса)
4. Сортировка по PID (+ по потреблению CPU + по памяти)
5. Вывод на экран и обновление (top обновляет список процессов)

1. Сбор общих данных 
	/proc/stat - содержится различная статистическая информация о системе. Такая, как частота процессора, количество тактов, количество сброшенных страниц памяти на диск, количество системных прерываний, время загрузки и т.д.
	/proc/meminfo - Здесь отображается вся доступная информация об оперативной памяти и пространстве подкачки.
	/proc/uptime - отображается сколько времени прошло после запуска компьютера. Первое число означает общее количество секунд после запуска компьютера, а второе время в режиме ожидания.
	/proc/PID/ - папки с номерами вместо имен. Каждый этот номер означает PID процесса, а эта папка содержит информацию о каждом запущенном в системе процессе. Когда процесс заканчивается, его каталог исчезает из системы.
	/proc/cpuinfo - очень подробная информация о процессоре. Производитель, частота, количество ядер, кэша, поддерживаемые расширения
